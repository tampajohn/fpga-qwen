This isolated experiment extends shared-input projection descriptors to single-token decode. Q/K/V share one normalized input and worker wakeup; gate/up share another. It removes 84 synchronization rounds per 28-layer token (two for QKV plus one for gate/up per layer). Every matrix still executes the original scalar SystemVerilog projection operation 0 and its original reduction order. It does not route a single token through batched arithmetic.

The optional `--scalar-group` builder flag requires `--group-projections` and creates a separate artifact. Neither live defaults nor precision change. A separate DPI entry validates three descriptor-array slots, a 1,024-element input and a 6,144-element output. Existing descriptor validation checks all matrix spans and contiguous output slices before waking workers. `run_group(..., scalar=true)` requires exactly one token, uses input/output stride 1 and records the correct input-copy savings. Worker exception propagation and shutdown paths are unchanged. Per-token counters are 56 grouped dispatches, 140 matrices and 84 saved barriers.

Validation includes mock scheduler coverage for scalar slices and invalid scalar token counts, real worker counts 1/3/8/17 with identical sampled predictions/full-logit bits, batch-tail regression, and 85/452-token contexts with eight exact continuation logits. The dump compatibility barrier recreates the worker pool; group counters must therefore be checked before that barrier.

The paired comparison uses identical B8 prefill and 32-token greedy requests, alternating baseline/candidate order across three pairs per context. Prefill and decode are reported separately. An earlier attention scoring run in another agent overlapped correctness accidentally; that run was stopped and discarded. Scalar paired scoring starts only after the explicit exclusive-window handoff.

The complete three-pair comparison is archived in `reports/scalar-group-paired.json`. Every timed/warmup request emitted the same 32 greedy IDs. Short decode ratios were 1.113, 1.186 and 1.126 (median 1.126); long ratios were 1.019, 1.196 and 1.213 (median 1.196). Observed per-engine median throughput was 40.80→46.94 tokens/s short and 30.35→34.08 long. The long runs varied substantially, so their entire range matters; these measurements are not universal hardware performance claims. Both models used the same B8 prefill. The optional change is worth further integration evaluation, but this experiment does not change production defaults.

The real two-test suite passed after correcting a test-only statistics assertion to account for the dump barrier resetting pool counters. Mock scheduling tests passed, including invalid scalar count rejection before dispatch/counter changes. Full held-out teacher-forced corpus evidence is recorded separately when complete.
