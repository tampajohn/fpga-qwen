This experiment uses the explicit `fp32_b1_fp64_prefill_fp32_kv` profile. Scalar and verification projections remain FP32, prefill projections and attention arithmetic remain FP64, and the coordinator stores KV payload as FP32 in a separate SystemVerilog module. C++ transports binary64 inputs and widens stored floats exactly for attention reads. Both general and canonical prefix reuse are disabled. There is no UI entry or default change in this adapter.

The candidate SHA256 is `c7a41fd46cb72ae0d2b1789c5be4b2926b8b7bb41ca440b0ecbe52fe6b3f5624`; the combined FP64-KV reference is `f17ae654f0c64ac47b63225a3406edc8bcd114cc86e67d56610090bf5d7c075d`. Both use eight workers, eight projection reduction lanes, canonical B8 prefill segmentation, and B4 verification capacity. Cross-profile differences are descriptive numerical measurements, not an exactness gate or evidence of quality improvement.

All 16 existing held-out examples and 292 authored target tokens were evaluated. Top-one agreement was 100%, token-weighted NLL delta was −1.5514951567929813e−7 nats, mean reference-to-candidate KL was 1.028381041459684e−12, and maximum absolute logit difference was 2.6702880859375e−5. The complete frozen-corpus/provenance report is `reports/fp32-kv-teacherforced.json`. The profiles are not bit-identical.

All nine free-running objective conversation cases produced identical token IDs and text. Both profiles passed four of nine strict checks; no baseline pass was lost. Repeating each candidate request reset its KV and reproduced the same IDs with zero prefix reuse. These narrow checks do not establish general model quality. The full conversation report is `reports/fp32-kv-conversations.json`.

Independent source review caught an initial fixed-array/open-array DPI ABI mismatch before evaluation. The tested artifact uses open arrays matching the host handles, includes the generated DPI header to catch future declaration mismatches, and statically checks actual FP32 array element types and payload size. Coordinator-only writes complete before synchronous worker publication; reset/truncate leave unreachable payload bytes intact, and subsequent positions overwrite them. No host neural arithmetic, GPU, or tensor framework was introduced.
